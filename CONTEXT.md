# Brain Battle — Session Context

## Game
Queens/Kings puzzle mobile (LinkedIn Queens clone).
Unity 6.0.75f1, C#, uGUI, Android + iOS.

## Mechanic singkat
- Grid NxN dibagi regions warna
- Tap sekali = dot, tap dua kali = crown
- 1 crown per row, col, region, tidak boleh adjacent
- Auto-dot row/col/region setelah crown place
- Undo, Restart, Tips tersedia
