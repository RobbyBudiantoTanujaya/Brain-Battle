# ScriptableObjects

Runtime data assets. Not loaded via `Resources.Load` — referenced directly as SerializeFields.

---

## Kings/Levels/

Contains all `LevelData` ScriptableObjects generated by `BrainBattle → Generate Kings Levels`.

### File Naming

```
Kings_Beginner_01.asset    → Difficulty="Beginner",   LevelNumber=1,  GridSize=5
Kings_Beginner_02.asset    → Difficulty="Beginner",   LevelNumber=2,  GridSize=5
...
Kings_Expert_01.asset      → Difficulty="Expert",     LevelNumber=1,  GridSize=7
...
Kings_Impossible_01.asset  → Difficulty="Impossible", LevelNumber=1,  GridSize=9
```

### How Levels Are Referenced

1. `LevelSelectSceneBuilder` runs `AssetDatabase.FindAssets("t:LevelData")` at build time and
   assigns the sorted array to `LevelSelectController._allLevels`.
2. `KingsSceneBuilder` does the same for `LevelLoader._allLevels`.
3. At runtime, `LevelLoader.GetLevel(n)` looks up by `LevelNumber` field.

### Adding More Levels

Run `BrainBattle → Generate Kings Levels`. The count per difficulty is configurable in
`KingsLevelGenerator.cs` as constants. After generation, re-run both scene builders.

### LevelData Asset Contents

Each asset holds:
- `LevelNumber` (int): 1-based index within its difficulty
- `Difficulty` (string): "Beginner" / "Expert" / "Impossible"
- `GridSize` (int): N for an N×N grid
- `Regions` (RegionDefinition[]): color + cell list per region
- `Solution` (Vector2Int[]): correct crown placements, `Vector2Int(col, row)`

Do NOT edit these assets manually — regenerate them via the menu item.
